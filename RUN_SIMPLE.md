# RecordGuard Core8 — Simple Startup

## Windows PowerShell

After extracting this folder:

```powershell
cd C:\sarthak\RecordGuard-Core8
python main.py
```

That is the normal startup command. No batch file is required.

## If Python is not installed / dependencies are missing

Install Python 3.10+ and then run:

```powershell
python -m pip install -r requirements.txt
python main.py
```

## Important

Run `python main.py` from the extracted RecordGuard folder.
