# Core34 — Organization & Clinic Administration

RecordGuard now provides an organization-scoped foundation for multi-clinic deployments.

## Capabilities
- Create/list/deactivate clinics within the current organization.
- Assign organization users to active clinics with member/lead scope.
- Assign patients to active clinics and mark one assignment as primary.
- Every management operation is organization-scoped and audited.
- Cross-organization user, patient, and clinic identifiers are rejected.

This is an administration and routing layer, not a clinical decision engine.
